# Jaal v3 (Flutter / Dart)

Build: GitHub par upload karein, Actions -> "Build APK" -> Run workflow -> artifact "jaal-apk" download karein.
Ya apne computer par:  bash setup.sh   phir   flutter build apk --release

Features: chat, files, voice message, live voice/video call, mesh relay, hop count, range test,
store-and-forward (purane chat paigham naye juray bande ko mil jate hain), themes, rang, text size,
bubble style, compact layout, English/Urdu (RTL), screen-on option, battery-optimization se chhoot.
